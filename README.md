# Fun-Themed POS System

## Overview
This is a colorful, fun-themed Point-of-Sale (POS) system designed for small shops. It provides an intuitive dashboard to manage products, employees, and transactions, while offering a smooth checkout experience. The system includes sales summaries, real-time stock management, and receipt printing via thermal printers.

---

## Features
- **Manage Products:** View product details, add stock, and maintain inventory accuracy.  
- **Manage Employees:** View employee details and add new staff.  
- **Transactions:** Track all sales, view transaction history, generate summaries, and print receipts.  
- **POS Page:** Add products to a cart, calculate totals, process payments, show change, and print receipts using a thermal printer.  

---

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL
